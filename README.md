## Deployment
This site is designed for deployment on GitHub Pages.

### How to deploy
1. Push all files to your GitHub repository (e.g., `username/username.github.io` or a custom repo)
2. In your repository settings, enable GitHub Pages (choose branch: `main` or `master`, folder: `/root`)
3. Your site will be available at `https://username.github.io/` or your custom domain

### Custom Domain
To use a custom domain (e.g., `hugobento.com`):
- Add a `CNAME` file with your domain name
- Configure DNS to point to GitHub Pages

## Local Development
